# RecallCam Roadmap

## Phase 1: Hackathon MVP

- local-only storage
- webcam face detection
- lightweight face matching
- speech capture and fact extraction
- overlay with name, relationship, last interaction, and helpful note

## Phase 2: Reliability Improvements

- stronger face detection and descriptor quality
- better low-confidence handling
- support cleaner multi-step enrollment

## Phase 3: Better NLP

- improved transcript normalization
- stronger extraction of relationship and interaction cues
- optional LLM-assisted summarization into structured fields

## Phase 4: Caregiver Tools

- edit and delete workflows
- profile review UX
- clearer consent and enrollment guidance

## Phase 5: Security And Sync

- encrypted storage strategy
- secure multi-device sync
- backend profile APIs with access controls

## Phase 6: Accessibility And Validation

- larger-font and simplified UI modes
- usability testing with caregivers
- feedback from dementia-care stakeholders
